# Объектно-ориентированная Java-реализация: запуск и тестирование

## 1. Что находится в проекте

Проект `interactive-presentations` — локальный desktop-прототип проигрывателя интерактивных 3D-презентаций на **Java 17 + jMonkeyEngine 3.9.0-stable + Maven**.

Реализовано:

- загрузка и сохранение сцены в JSON;
- рекурсивная иерархия `SceneObjectData` через `parentId`;
- проверка отсутствующих родителей, повторяющихся идентификаторов и циклов;
- импорт GLB 2.0 с восстановлением иерархии узлов;
- создание синтетического корня, если у GLB несколько корневых узлов;
- отображение GLB-модели электродвигателя;
- наведение и подсветка, выбор ближайшего объекта лучом по щелчку;
- Markdown-описания и изображение в информационной панели;
- составное событие из двух анимаций;
- повторная активация события с изменением направления без скачка;
- сохранение локальных трансформаций по F5;
- 16 автоматических JUnit-тестов.

## 2. Какие программы установить

### Обязательно

1. **JDK 17** — например, Eclipse Temurin 17: <https://adoptium.net/temurin/releases/?version=17>.
   - При установке Windows включите опцию добавления Java в `PATH` или настройте `JAVA_HOME` вручную.
   - JRE недостаточно: для сборки нужен JDK.
2. **Apache Maven 3.9+**: <https://maven.apache.org/download.cgi>.
   - Распакуйте архив и добавьте каталог `bin` в переменную `PATH`.
   - Maven сам скачает jMonkeyEngine и остальные зависимости, поэтому отдельно устанавливать jMonkeyEngine SDK не нужно.
3. Актуальный драйвер видеокарты с поддержкой OpenGL. Для запуска необходимо графическое окружение.

### Желательно, но не обязательно

- **IntelliJ IDEA Community**: <https://www.jetbrains.com/idea/download/> — для редактирования и запуска кода.

Проверка установки в терминале:

```bash
java -version
mvn -version
```

Должны отображаться JDK 17 или новее и Maven. Команды ниже проверены на JDK 17 и Maven 3.8.7.

## 3. Быстрый запуск

Распакуйте архив и откройте терминал в каталоге проекта:

```text
interactive-presentations/
├── pom.xml
├── data/
├── src/
└── target/interactive-presentations-1.0.0.jar
```

### Windows

Дважды щёлкните `run.bat` или выполните:

```bat
run.bat
```

### Linux / macOS

```bash
sh run.sh
```

В архив включён готовый JAR, поэтому для первого запуска достаточно JDK. Если JAR отсутствует, скрипт вызовет Maven и соберёт его.

Универсальная команда из корня проекта:

```bash
java -Dfile.encoding=UTF-8 -jar target/interactive-presentations-1.0.0.jar
```

**Важно:** запускайте приложение из корня `interactive-presentations`, иначе оно не найдёт каталог `data` с моделью, шрифтом и JSON-сценой.

## 4. Управление и ручная проверка

| Действие | Результат |
|---|---|
| Навести указатель на компонент | Жёлтая рамка; описание ещё не открывается |
| Щёлкнуть ЛКМ по компоненту | Выбор ближайшего пересечения, описание и изображение |
| Нажать E или ПКМ | Запуск события выбранного объекта или его родителя |
| Повторно нажать E во время события | Направление меняется с текущего прогресса, без скачка |
| Нажать E после завершения | Обратное проигрывание |
| F5 | Сохранение сцены и текущих трансформаций в JSON |
| R | Возврат камеры в исходное положение |
| WASD и перетаскивание ЛКМ | Перемещение и поворот камеры |
| Esc | Выход |

Прогресс события показывается внизу окна. Само значение прогресса не сохраняется: сохраняются трансформации объектов на момент F5.

## 5. Сборка и автоматические тесты

Из корня проекта:

```bash
mvn clean test
mvn package
```

Ожидаемый результат: `BUILD SUCCESS`, **16 тестов, 0 ошибок, 0 падений**.

Отчёты появятся в `target/surefire-reports/`.

Тесты покрывают:

- JSON round-trip и обработку повреждённого JSON;
- нормальную иерархию, отсутствующего родителя, цикл и дубликаты ID;
- импорт узлов GLB, синтетический корень и проверку сигнатуры;
- чтение прилагаемой GLB-модели;
- выбор ближайшего объекта и игнорирование объектов без ID;
- ограничение прогресса диапазоном `[0;1]`;
- обратимость без скачка и синхронизацию двух каналов события.

Запуск через Maven без отдельного JAR:

```bash
mvn exec:java
```

## 6. Запуск в IntelliJ IDEA

1. Выберите **File → Open** и откройте `pom.xml` или каталог проекта.
2. Дождитесь загрузки Maven-зависимостей.
3. Откройте `src/main/java/ru/kuzma/presentation/PresentationApp.java`.
4. Нажмите зелёный треугольник у метода `main`.
5. В конфигурации запуска проверьте:
   - **JRE:** 17;
   - **Working directory:** корень проекта `interactive-presentations`.

Для тестов щёлкните правой кнопкой по `src/test/java` и выберите **Run All Tests**.

## 7. Импорт собственной GLB-модели

Требования к файлу:

- GLB 2.0, а не автономный `.gltf`;
- buffers и изображения встроены в GLB;
- Draco-сжатие не используется;
- узлы образуют дерево без циклов;
- рекомендуется задавать узлам уникальные имена: по ним связываются описания и объекты сцены.

Команда:

```bash
java -Dfile.encoding=UTF-8 -jar target/interactive-presentations-1.0.0.jar --import path/to/model.glb data/my-scene.json
```

Импортёр скопирует модель в `data/models`, создаст `data/my-scene.json` и выведет число узлов, mesh и анимаций. После этого отредактируйте названия и `descriptionMarkdown` в JSON и запустите:

```bash
java -Dfile.encoding=UTF-8 -jar target/interactive-presentations-1.0.0.jar --scene data/my-scene.json
```

Если импортированная сцена не содержит событий, клавиша E сообщит об их отсутствии. Событие можно добавить по образцу в `data/demo-scene.json`.

## 8. Где редактировать содержимое

Основной файл: `data/demo-scene.json`.

- `name` — название сцены;
- `backgroundColor` — цвет фона в HEX;
- `models[].filePath` — путь к GLB относительно `data`;
- `objects[].parentId` — родительский объект;
- `objects[].sourceNodeKey` — имя соответствующего узла GLB;
- `objects[].transform` — локальные положение, поворот и масштаб;
- `objects[].descriptionMarkdown` — описание;
- `objects[].imagePaths` — изображения относительно `data`;
- `events[].animations` — каналы `ROTATE_X`, `ROTATE_Y`, `TRANSLATE_Y`, амплитуда и длительность.

После ручного редактирования сохраните файл в UTF-8. При ошибке ссылок или цикле приложение отклонит сцену с сообщением в терминале.

## 9. Структура кода

```text
src/main/java/ru/kuzma/presentation/
├── PresentationApp.java          # окно, 3D-сцена, ввод, HUD
├── ImportCli.java                # консольный импорт GLB
├── model/                        # сериализуемая модель сцены
├── storage/JsonSceneRepository.java
├── scene/HierarchyValidator.java
├── scene/DemoSceneFactory.java
├── importing/GlbImportService.java
├── interaction/SelectionService.java
└── animation/
    ├── ReversibleEvent.java
    └── AnimationRuntime.java
```

Расчётная сложность:

- импорт GLB: `O(b + n + v)`;
- выбор: `O(m + h + d)`;
- подготовка события: `O(k + t)`;
- обновление кадра активного события: `O(c)`.

## 10. Если что-то не запускается

- **`java` или `mvn` не распознаётся:** проверьте `PATH`, перезапустите терминал.
- **Maven сообщает, что нужен другой JDK:** проверьте `JAVA_HOME`; он должен указывать на каталог JDK 17, а не JRE.
- **`data/...` или модель не найдены:** перейдите в корень проекта перед запуском.
- **Повреждённая зависимость Maven:** выполните `mvn clean package -U`.
- **Чёрный экран или ошибка OpenGL:** обновите драйвер видеокарты и проверьте, что не используется ограниченный удалённый рабочий стол.
- **Ошибка сцены в JSON:** проверьте ID, `parentId`, `rootObjectId` и положительную длительность всех анимаций.
